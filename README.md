# Annoteer

Annoteer is a website for annotating textual data.

## How to

You can work on your annotations in groups and create different projects.
For every project you can define your own labels for multi or single label decisions.
The csv-files can be directly uploaded and your finished annotations can be downloaded.

So that all of the contributors of a project are informed about the procedure, you can leave instructions and a description for each project.

## Features

- manage projects and labels
- import your own csv-files
- annotate your data (alone or in groups)
- export your annotated sequences as csv-files
